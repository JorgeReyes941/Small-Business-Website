This project is a mock website I made for a fake company and that I built from scratch for a class assignment to practice core web development skills. It includes a multisection layout, responsive design, and basic interactivity with JavaScript. I used HTML, and JavaScript, and the project can be run by opening the index.html file in a browser. This project helped me understand how these technologies work together and improved my ability to structure code and design layouts. It was also one of my favorite projects because it felt more practical and real compared to other assignments.
